# Quiero — Spanish by what you'll use most

A Spanish learning web app built on Ron Ragsdale's course materials and his
"Laws of Probability of Usage": learn the most-used words first (quiero,
tengo que, necesito), start with verbs, group words by category, and practice
by retrieval rather than rereading.

Built with Claude Code for Wildfire Labs.

## How the method maps to the app

| From the book | In the app |
| --- | --- |
| Bell curve of word usage; start at the apex | Home screen progress map: each unit is a slice under the curve, filled outward from the centre as words get stronger |
| Seven levels, Functional → Bilingual | Units grouped by level (Functional, Hi Functional, Conversational, Hi Conversational) |
| Verbs first; organized by category | Verb units by category (senses, communication, mind, movement, states of being) interleaved with kid-level nouns (family, food, animals, body) |
| The 70 verbs you must know: 14 irregulars, 18 stem changers, 15 awkwards, 20 reflexives | Dedicated units, each with conjugation tables in the book's tenses |
| Retrieval practice (English, pause, recall the Spanish) | New words open with a recall card: see the English, say it, reveal, grade yourself |
| "Handles" explaining why | Shown on each unit's intro screen |

## Exercises

Recall cards, pick the Spanish, listen and choose, type it (accent and article
mistakes are accepted but flagged), build the sentence from word tiles, and
pick the right conjugation. Missed words return once at the end of the lesson.
A Leitner-box scheduler (boxes 0–5) drives the Weak words review.

## Content

26 units and about 400 words and phrases, in `src/data/curriculum.ts`.
Conjugations are generated by `src/data/verbs.ts` from the AR/ER/IR models,
with irregular and stem-changing forms listed explicitly.

Sources (scanned PDFs, OCR'd and hand-checked):
- Part I: Verbs (Forward, verb categories, regular/irregular/stem-changing/awkward/reflexive conjugations, Getting off the Dime)
- Part II: Spanish Grammar (sentence construction, time frames, interrogatives)
- Part III: Stuff (vocabulary by category)

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (deploys to Vercel as-is)
STATIC_EXPORT=1 npm run build   # static site in ./out for previews
```

Audio uses the browser's built-in speech synthesis, preferring a Mexican
Spanish (es-MX) voice when the device has one.

## Roadmap

- **Accounts and sync (week 3):** Supabase auth and the tables in
  `supabase/schema.sql`. Progress currently saves in the browser via
  `src/lib/progress.ts`, which has the same shape.
- **More content:** remaining Part III categories (kitchen, clothing, weather,
  professions, sports), Part II pronouns, and the past/future tenses for the
  70 core verbs.
- **Later:** speaking practice with speech recognition; AI-generated practice
  sentences limited to words the learner has unlocked.
